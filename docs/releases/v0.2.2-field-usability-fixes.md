# v0.2.2-field-usability-fixes

Released 2026-09-12.

Usability release for the Local Node. It closes the three barriers observed
in the August 2026 sessions with three primary-care nurses in Táriba,
Táchira (see [`docs/qa/usability-sessions-2026-08.md`](../qa/usability-sessions-2026-08.md)).
No clinical logic changes; the public review at
[pediatric.kynode.io](https://pediatric.kynode.io/) runs this release.

## Changed

- **Persistent save confirmation** (#11, PR #14). After saving an
  encounter, the weekly input or the climate context, a "saved · time"
  line now stays under the save button until the next save; the toast
  alone disappeared after ~3 seconds and participants re-saved to be
  sure. Save toasts stay 5 seconds.
- **Weekly routine stepper** (#13, PR #15). The Surveillance view opens
  with a four-step indicator — weekly input → climate context → prepare
  export → brief — marked done / current / pending from local state.
  Each step links to its panel. The routine no longer depends on a
  moderator explaining the order.
- **Plain-language glosses** (#12, PR #16). Field hints under the
  weekly-input indicator, current count and baseline counts; the growth
  z-score and the surveillance-signal z-score now carry distinct,
  explained labels instead of one shared "Z-score" string. EN and ES.

## Fixed

- Static assets are served with a new cache-busting version
  (`?v=0.2.2-ux`), so nodes that had cached the previous UI pick up the
  changes on update.

## Evidence

- Usability sessions record: aggregate results (usefulness 4.7/5,
  willingness to use daily 4.0/5, ease of use 3.3/5; n = 3), method and
  limits. No participant data is stored in the repository.
- Test baseline unchanged: 184 tests, coverage gate 80 % (93.79 % at
  release). The index contract test now asserts the stepper and the
  save-confirmation elements.

## Not in this release

- A second round of sessions on the updated UI is planned; the
  ease-of-use score above is the pre-fix measurement.
- Grant-funded work (sync, roles, full IMCI, institutional adapters)
  stays on the roadmap; see `ROADMAP.md`.
